Node.js

Pošalji email

HTML/CSS forma + Node backend (SMTP preko nodemailer). Radi na Netlify (/.netlify/functions/send-email), lokalno sa npm run dev, ili bilo gde sa npm start (Express na portu 3000).

Nova poruka

Kopiraj .env.example u .env (Gmail App Password). Na Netlify-u iste vrednosti kao SMTP_* i FROM_* env varijable.
